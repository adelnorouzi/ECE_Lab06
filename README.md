## Summary 
In this lab we learned how the truth tables for adders such as and and xor compare to the outputs and carry of adding binary numbers, We also learned how to implement switches using xor gates to simulate addition, with carry ins and carry outs. 

### 1 - How might you add more than two bits together?
You can chain full adders together to add multiple bit numbers using carry ins and carry outs 

### 2 - What is the importance of the XOR gate in an adder?
the xor gate is what is responsible for calculating the sum output in a full adder 

### 3 - What is the largest number a two bit adder can handle? What happens when you go over?
The largest number a two bit adder can handle is 3 and if you go over then you will cause an overflow and receive incorrect answers.
